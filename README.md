# MediRisk AI

## Intelligent Patient Health Risk Assessment System

### About

MediRisk AI is a Python-based healthcare project developed to assess a patient's health condition using basic health parameters. The system analyzes BMI, body temperature, oxygen level, heart rate, blood pressure, blood sugar, and medical history to generate a health risk score and a detailed health report.

It also provides personalized health recommendations and stores patient records in CSV format for easy record management.

This project was built to improve my Python programming skills by applying core concepts to solve a real-world healthcare problem.
